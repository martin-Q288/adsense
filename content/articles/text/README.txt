원고 작성 규칙 (2026-08-02 개정)
========================================
위 한 줄은 제목 칸에, 아래부터 본문 칸에
========================================

키워드는 반드시 SERP 확인 후 선정

docs/13, docs/14 참조. 순서:

1. python3 tools/rank_keywords.py --longtail --info-only
2. 후보를 실제로 검색해서 상위 10개 확인
3. 블로그(티스토리·브런치·독립 콘텐츠 사이트)가 3개 이상 → 진행
4. 정부·법무법인·법무사·전용도구만 있으면 → 스킵

SERP 실측으로 확인된 지형 (2026-08-02, 10건)

진입 가능
  키워드: 실업급여 조건 / 퇴직금 계산 / 전기요금 누진 / 버팀목 전세대출 / 정부 지원금
  상위 노출: 블로그·콘텐츠 사이트 다수

조건부
  키워드: 전세보증보험 가입방법
  상위 노출: HUG + 핀테크 콘텐츠팀 + 중소 콘텐츠 사이트

불가
  키워드: 실업급여계산기 / 부동산양도세계산기
  상위 노출: 정부·대형플랫폼·전용도구

불가
  키워드: 청년미래적금
  상위 노출: 은행·공식기관

불가
  키워드: 개인회생 신청자격 / 상속등기 서류
  상위 노출: 법무법인·법무사

갈린 기준: 그 정보를 알려주는 것이 누군가의 영업으로 이어지는가.
수임형(법무사·변호사)·도구형·브랜드형은 전문 사업자가 방어합니다.
정책·제도 정보는 알려줘도 아무도 돈을 못 벌어서 비어 있습니다.

GEO 구조 필수 (docs/14)

AI는 페이지가 아니라 청크(문단) 를 임베딩해 검색합니다.

· 각 H2 섹션이 단독으로 읽혀도 말이 되어야 합니다
· 출처를 글 하단이 아니라 해당 섹션 안에 표기
· 대명사로 앞 섹션 참조 금지 ("이것", "앞서 말한")
· 섹션마다 수치 1개 이상 + 기준일
· 법령·공식 문구 직접 인용 1개 이상
