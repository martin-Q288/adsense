결론부터: 쿠팡 고객센터 전화번호는 1577-7011입니다. 자동응답을 끝까지 듣지 말고 안내가 시작되면 0번을 눌러 상담원 연결로 넘어가는 편이 빠릅니다. 대기가 길 때는 전화보다 쿠팡 앱의 1:1 채팅 상담이 대체로 더 빠릅니다.

  • 전화: 1577-7011
  • 상담원 연결: 안내 중 0번
  • 채팅 상담: 쿠팡 앱 → 마이쿠팡 → 고객센터 → 상담하기

전화로 연결하기

  1. 1577-7011 로 전화
  2. 주문번호가 있으면 미리 준비 (앱 → 마이쿠팡 → 주문목록)
  3. 자동응답 안내가 시작되면 0번
  4. 상담원 연결

점심시간(12~13시)과 월요일 오전은 대기가 깁니다. 급하지 않다면 평일 오후 3~5시가 상대적으로 한산합니다.

채팅 상담이 더 빠른 경우

전화 대기가 길 때는 앱 채팅이 낫습니다.

  1. 쿠팡 앱 실행
  2. 하단 마이쿠팡 탭
  3. 아래로 내려 고객센터
  4. 상담하기 선택

채팅은 챗봇이 먼저 응대하는데, 원하는 답이 안 나오면 "상담원 연결"이라고 입력하면 사람으로 넘어갑니다. 주문 내역이 자동으로 연결돼 있어 주문번호를 불러줄 필요가 없다는 점이 전화보다 편합니다.

운영시간

쿠팡은 채널별로 운영시간이 다르고 안내가 자주 바뀝니다. 24시간이라는 안내와 09:00~19:00라는 안내가 함께 돌아다니는 이유입니다.

정확한 운영시간은 쿠팡 앱 → 마이쿠팡 → 고객센터 화면 상단에 그 시점 기준으로 표시됩니다. 전화 전에 이 화면을 먼저 확인하는 편이 확실합니다.

자주 묻는 질문

Q1. 1577-7011이 안 걸립니다.

통화량이 많으면 자동으로 끊길 수 있습니다. 앱 채팅 상담으로 넘어가는 편이 빠릅니다.

Q2. 판매자인데 같은 번호로 문의하나요?

아닙니다. 판매자 문의는 쿠팡 윙(wing.coupang.com) 로그인 후 온라인 문의로 접수합니다. 1577-7011은 구매 고객용입니다.

Q3. 쿠팡이츠·쿠팡플레이도 이 번호인가요?

서비스별로 문의 창구가 다릅니다. 각 앱 안의 고객센터를 이용하세요.

Q4. 상담 내용을 기록으로 남기려면?

채팅 상담을 이용하면 대화 내용이 앱에 저장됩니다. 분쟁 소지가 있는 건은 전화보다 채팅이 안전합니다.
