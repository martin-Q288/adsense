8월 1일 발행 원고 (티스토리 HTML)

폰에서 바로 발행할 수 있게 두 가지 복사 방식을 넣었습니다.

티스토리 모바일 앱에는 HTML 모드가 없습니다. (다음 고객센터 공식 안내) 그래서 복사 버튼을 둘로 나눴습니다.

방법 1 · 앱에서 바로 서식 복사

티스토리 앱 → 글쓰기 → 기본 모드에 그대로 붙여넣기. 제목·굵기·표·목록이 서식 그대로 들어갑니다. 가장 빠릅니다.

단, 광고 코드는 위지윅에 안 붙습니다. 본문 광고 없이 나가고 자동광고(앵커·전면·페이지 내 광고 전부 ON)에 맡기면 됩니다.

방법 2 · 데스크톱 모드에서 HTML 복사

수동 광고 3개까지 그대로 넣고 싶을 때. 폰 브라우저에서 PC 화면을 띄웁니다.

아이폰 Safari 주소창 왼쪽 ᴀA → 데스크탑 웹사이트 요청
안드로이드 Chrome 우측 상단 ⋮ → 데스크톱 사이트 체크

그다음 tistory.com 로그인 → 글쓰기 → 우측 하단 기본모드 → HTML → 붙여넣기. 이때는 자동광고의 페이지 내 광고를 OFF로 두세요.

붙인 뒤 ca-pub-…와 /entry/글주소를-여기에를 실제 값으로 교체.
