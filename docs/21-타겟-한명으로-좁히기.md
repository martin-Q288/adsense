# 21. 타겟을 한 명으로 좁히기

2026-08-05. "타겟이 명확하지 않다"는 지적 이후 정리.

## 1. 무엇이 문제였나

프런트매터의 `누가` 항목이 이랬다.

> 8월 이사 시즌에 전세 계약을 앞둔 20~40대. 보증금이 전 재산인 경우가 대부분

**"20~40대"는 타겟이 아니다.** 경제활동인구 절반이다. docs/17에서 "검색 의도"를
잡는 데는 성공했지만("계약 도장 찍기 직전"), **그 상황에 있는 사람이 정확히
누구인지**는 여전히 안 잡았다.

본문도 마찬가지였다. 전세사기 원고 하나에서:

- 계약 앞두고 오늘 가계약금 넣으라는 사람 (메인)
- 이미 계약해서 불안한 사람 (섹션 7)
- 월세인 사람 (FAQ)
- 보증금 적은 사람 (FAQ)
- 계약금 보내고 신탁을 발견한 사람 (FAQ)

**다섯 명을 한 글에서 다 챙기려고 했다.** 각각에게 필요한 답은 다른데
분량은 나눠 가지니, 결과적으로 아무에게도 충분하지 않은 글이 됐다.

## 2. 규칙 — 이름을 붙일 수 있어야 타겟이다

`누가` 항목에 나이대나 "직장인", "20~40대" 같은 인구통계를 적지 않는다.
**그 사람이 지금 뭘 하고 있는지 한 문장으로 적는다.**

```
나쁨   8월에 전세 계약을 앞둔 20~40대
좋음   부동산에서 오늘 가계약금 넣으라고 재촉받은, 생애 첫 전세를 구하는 사람
```

판정 기준은 하나다.

> **이 문장을 읽고 "어, 나 얘기네"라고 반응할 사람이 한 종류로 좁혀지는가?**
> 두 종류 이상 떠오르면 아직 안 좁혀진 것이다.

## 3. 부차적인 독자는 밀어내되, 없애지 않는다

같은 키워드를 검색해도 상황이 다른 사람이 있다. 이들을 무시하지는 않되,
**메인 타겟과 같은 무게로 다루지 않는다.**

- 본문 중간에 섞지 않고 **명확한 경계 문구로 분리**한다
  ("이 글은 계약 전인 분을 위한 글입니다. 이미 계약하셨다면 여기부터 보세요")
- 전체 섹션을 할애하지 않고 **짧게 처리하거나 다른 글로 넘긴다**
- FAQ에 넣더라도 **메인 타겟이 실제로 물을 법한 것만** 남긴다

이렇게 하면 정보량은 유지하면서도 "이 글은 누구를 위한 글인가"가
읽는 사람에게 즉시 잡힌다.

## 4. 도입부에서 타겟을 한 문장으로 못박는다

결론(docs/14) 다음, 검색 의도 짚기(docs/17) 다음에 **타겟 확인 문장**을 넣는다.

```
결론      전세사기는 계약서에 도장 찍기 전에 볼 수 있었던 숫자를 안 봐서 당한다
의도 짚기  부동산에서 "오늘 가계약금 넣으셔야 한다"는 말 들으셨나요?
타겟 확인  이 글은 생애 처음 전세를 구하는, 지금 계약을 앞둔 분을 위한 글이에요.
           이미 계약하셨다면 [이미 계약했다면] 섹션으로 바로 가세요.
```

세 번째 줄이 새로 추가한 것이다. 이 한 줄이 독자에게 "나를 위한 글이 맞다"
또는 "나는 다른 섹션을 봐야 한다"를 즉시 알려준다.

## 5. 8월 전세 시리즈 — 타겟 고정표

시리즈 전체가 같은 독자 여정을 따라가도록 타겟을 미리 고정한다.
한 사람이 순서대로 검색할 법한 키워드로 시리즈를 엮는다.

| 순서 | 원고 | 메인 타겟 (한 명) |
|---|---|---|
| 1 | 전세사기 피하는 법 | 생애 첫 전세, 오늘 가계약금 넣으라고 재촉받은 사람 |
| 2 | 전세자금대출 조건 | 그 집을 계약하기로 했고, 자기 돈만으로 보증금이 안 되는 사람 |
| 3 | 월세 세액공제 | (예정) 전세가 아니라 월세로 확정한 뒤, 연말정산에서 뭘 챙길 수 있는지 궁금한 사람 |
| 4 | 주택담보대출 금리 비교 | (예정) 전세를 포기하고 매수로 갈아탄, 대출을 갈아타야 하는 사람 |
| 5 | DSR 계산 방법 | (예정) 대출 한도가 안 나온다는 말을 듣고 이유를 알고 싶은 사람 |
| 6 | 부동산 중개수수료 계산 | (예정) 계약서에 서명하기 직전, 중개수수료가 맞는지 확인하려는 사람 |
| 기존 | 전입신고·확정일자 | 잔금일이 잡힌, 이사 당일 할 일을 정리하려는 사람 |
| 기존 | 전세보증보험 가입방법 | 계약은 끝났고, 보증보험 가입 기한을 놓칠까 걱정하는 사람 |

3~6번은 같은 사람이 아니라 **여정에서 갈라지는 다른 사람들**이다. 전세를
포기하고 매매로 간 사람(4, 5)과 월세로 간 사람(3)은 서로 다른 글의 타겟이지,
한 글 안에서 같이 다루지 않는다.

## 6. 발행 전 체크

```
[ ] `누가` 항목이 인구통계가 아니라 상황 한 문장인가
[ ] 그 문장으로 독자가 한 종류로 좁혀지는가
[ ] 부차적 독자가 본문에 섞이지 않고 경계 문구로 분리됐는가
[ ] 도입부에 "이 글은 ~를 위한 글입니다" 타겟 확인 문장이 있는가
```

## 7. 기존 원고 중 재작업이 필요한 것

이번에 전세사기·전세자금대출 2편은 이 규칙으로 다시 손봤다. 나머지 8편은
`누가` 항목 자체가 없거나(docs/17 이전 작성분) 광범위한 인구통계로만 적혀
있어 같은 재작업이 필요하다. 우선순위는 발행 큐 순서(docs/18)를 따른다.
