# 13. "금맥" 판단 정정 — SERP를 직접 확인한 결과

2026-08-02, 네이버 실측 데이터를 받고 **"실업급여계산기가 금맥"이라고 한 판단은 틀렸습니다.** SERP를 직접 확인하지 않고 광고 경쟁도만 보고 내린 결론이었습니다. 정정 근거와 수정된 기준을 남깁니다.

## 1. 무엇을 틀렸나

`docs/12`에 "compIdx는 광고 경쟁도이지 SEO 경쟁도가 아니다"라고 써 놓고, 바로 다음 절에서 낮은 광고 경쟁도를 기회 신호로 해석했습니다. 자기 문서와 모순입니다.

## 3. 두 가지 오류

### 3-1. 낮은 광고 경쟁도는 기회가 아니라 수익성 경고

애드센스 RPM은 **광고주 입찰**이 만듭니다. 광고가 0~2개라는 건 그 트래픽에 돈을 낼 광고주가 없다는 뜻이고, 그 페이지에 붙을 광고 인벤토리도 빈약하다는 뜻입니다. **트래픽이 와도 RPM이 바닥입니다.**

- 계산기 질의: 계산기 쓰는 사람에게 팔 게 없음 → 광고주 없음
- 청년미래적금: 정부 정책상품 → 광고할 주체 자체가 없음

### 3-2. 광고 경쟁과 SEO 경쟁은 같은 방향

광고 10개가 붙는다는 건 법무법인·보험사가 클릭당 수만원을 내는 시장이라는 뜻입니다. 그런 시장은 **SEO에도 전문 인력을 투입**합니다. 개인회생신청자격 상위가 전부 법무법인인 이유입니다.

초판 공식 `(1 − 경쟁도)²`는 경쟁도가 낮을수록 점수를 올렸는데, **RPM을 깎는 방향**이었습니다.

## 4. 실제 지형

| | 광고 경쟁 낮음 | 광고 경쟁 높음 |
|---|---|---|
| **SEO 경쟁 낮음** | RPM 바닥. 트래픽만 있고 돈 안 됨 | ← **여기가 목표. 단, 좁음** |
| **SEO 경쟁 높음** | 최악 (도구·공식사이트 영역) | 법무법인·보험사 영역. 진입 불가 |

우상단 칸이 목표인데, 대형 키워드에서는 거의 존재하지 않습니다. **검색량이 크면 반드시 누군가 방어하고 있습니다.**

## 5. 그럼 어디에 있나 — 초롱테일

수집한 11,948개를 검색량대별로 나눠 봤습니다.

| 월검색량 | 낮음 | 중간 | 높음 | 계 |
|---|---|---|---|---|
| 300~1,000 | 88 | 977 | **4,537** | 5,602 |
| 1,000~3,000 | 48 | 746 | **2,582** | 3,376 |
| 3,000~1만 | 28 | 470 | 1,322 | 1,820 |
| 1만~5만 | 16 | 275 | 621 | 912 |
| 5만+ | 8 | 94 | 136 | 238 |

**검색량 300~3,000 + 광고 5개 이상 = 7,986개, 합계 월 799만회.**

이 구간이 우상단입니다. 이유가 명확합니다.

- **광고는 붙습니다** — 같은 광고그룹에 속하므로 단가가 대형 키워드와 비슷합니다
- **전담 페이지는 없습니다** — 법무법인이 월 800회짜리 질의에 전용 페이지를 만들 유인이 없습니다

개별로는 작지만 558편을 쌓으면 이 풀의 7%를 가져갑니다.

## 6. 수정된 도구 사용법

```bash
# 신규 블로그 진입 구간 프리셋
python3 tools/rank_keywords.py --longtail --info-only -o keywords/ranked.csv
```

`--longtail` = 검색량 300~3,000 + 광고 5개 이상
`--info-only` = 정보형 질의만 (도구형·브랜드형·단일어 제외)

**수정된 점수 공식**
```
점수 = log10(검색량) × 단가티어 × RPM계수 × 질의유형계수

RPM계수  = (0.4 + 광고경쟁도) × (0.5 + 광고수/10)    ← 높을수록 좋음
질의유형 = 정보형 1.30 / 단일어 0.55 / 브랜드형 0.30 / 도구형 0.15
```

도구형(계산기·조회·발급)에 0.15를 준 이유는 위 SERP 확인 결과입니다. 정부·대형플랫폼·전용도구가 독점합니다.

## 7. 여전히 자동화 못 하는 것

**질의유형은 SEO 경쟁의 근사치일 뿐입니다.** 실제로 블로그가 상위에 있는지는 검색해 봐야 압니다. 발행 전 30초 확인은 대체 불가능합니다.

- 상위 10개에 블로그(티스토리·네이버·워드프레스)가 3개 이상 → 진입 가능
- 전부 공식기관·법무법인·대형플랫폼 → 스킵

## 8. 결론

실측 데이터를 붙였더니 **원래 8월 계획(이슈 파생 롱테일 + 시즌 선점)이 옳았다는 게 우회해서 확인**됐습니다. 대형 고단가 키워드는 처음부터 남의 땅이었고, 신규 블로그의 전장은 초롱테일과 시의성입니다.

바뀐 것은 이제 **어느 롱테일인지를 실측 데이터로 고를 수 있다**는 점입니다. 8축 기계 전개 대신 469개의 검증된 후보가 있습니다.
