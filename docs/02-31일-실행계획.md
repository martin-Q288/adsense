# 02. 31일 실행계획 (2026-08-01 ~ 08-31)

전제: [00-현실점검.md](00-현실점검.md)의 결론을 받아들인 상태. 8월의 목표는 **월 run-rate ₩80만~250만 + 9~12월 월 1,000만원을 만들 자산 구축**입니다.

## 포트폴리오 설계 — 블로그 4개를 어떻게 나눌 것인가

4개를 같은 성격으로 만들면 리스크가 4배가 아니라 1배입니다. 니치·플랫폼·수익모델을 전부 분산합니다.

| # | 니치 | 플랫폼 | 1차 수익원 | 역할 |
|---|---|---|---|---|
| A | **고단가 YMYL** — 보험/대출/세금/정부지원금 | 티스토리 (승인 계정) | 애드센스 (RPM 5,000~15,000) | 수익 주력. 글당 가치 최고 |
| B | **이슈/트렌드** — 시사, 연예, 스포츠, 생활이슈 | 티스토리 | 애드센스 (RPM 낮음, 볼륨 큼) | 트래픽 폭발 담당. 구글 디스커버 노림 |
| C | **제품 리뷰/구매가이드** | 티스토리 | **쿠팡파트너스** + 애드센스 | 8월 내 실입금 가능한 유일 라인 |
| D | **에버그린 정보** — 방법/절차/서식 | 워드프레스 (자체 도메인) | 애드센스 | 플랫폼 리스크 헤지. 장기 자산 |

**왜 이 배분인가**
- A는 PV당 수익이 B의 5~10배입니다. 같은 노동으로 수익이 가장 큽니다. 단 YMYL이라 신규 사이트 순위가 느립니다 → 그래서 B가 필요합니다.
- B는 단가는 낮지만 **신규 사이트도 하루 만에 수만 PV를 받을 수 있는 유일한 채널(구글 디스커버)**에 올라탈 수 있습니다. 8월 안에 숫자를 만들 유일한 고변동 레버입니다.
- C의 쿠팡파트너스는 정산이 익월 15일경으로 애드센스보다 빠르고, 승인 대기가 없습니다. **8월 활동 → 9월 중순 입금**으로 애드센스(9월 하순)보다 앞섭니다.
- D의 워드프레스는 티스토리 정책 변경/블로그 저품질 판정에 대한 보험입니다. 도메인이 내 자산으로 남습니다.

## 주차별 계획

### 1주차 (8/1~8/7) — 인프라 구축 + 발행 시작

**8/1 (오늘)**
- 애드센스 계정 상태 점검: 주소 PIN 인증 완료 여부, 세금정보(W-8BEN) 제출, 지급수단 등록. **이게 안 돼 있으면 아무리 벌어도 입금 0원입니다. 최우선.**
- 기존 승인 블로그를 A/B/C/D 중 무엇으로 쓸지 결정 (기존 주제와 가장 가까운 것)
- 나머지 3개 블로그 개설. 티스토리는 계정당 5개까지 가능 → 계정 하나로 A·B·C 커버 가능
- 애드센스 → 사이트 추가, ads.txt 설정

**8/2~8/3**
- 블로그별 스킨/레이아웃 세팅, 광고 유닛 배치 ([03](03-키워드-수익구조.md) 참조)
- 구글 서치콘솔 + 네이버 서치어드바이저 + 빙 웹마스터 등록, 사이트맵/RSS 제출
- 워드프레스(D): 도메인 구매, 호스팅, 테마 설치
- 쿠팡파트너스 가입 신청 (승인 며칠 소요 → 지금 신청)

**8/4~8/7**
- 키워드 리서치: 블로그당 50개 시드 확보 → `tools/keyword_score.py`로 우선순위화
- 발행 시작. **블로그당 하루 2~3편, 합계 하루 8~12편**
- 목표: 1주차 말 누적 40~60편

### 2주차 (8/8~8/14) — 발행 가속 + 색인 확인

- 색인 상태 점검. 서치콘솔에서 색인 안 된 글 → URL 검사로 개별 요청
- 블로그 B: 이슈 키워드 대응 체계 가동. 구글 트렌드 실시간 급상승 모니터링 → **이슈 발생 후 30~90분 내 발행**이 핵심. 늦으면 의미 없습니다
- 블로그 C: 쿠팡파트너스 승인되면 즉시 링크 삽입 시작
- 발행 유지: 하루 10~15편
- 목표: 누적 110~150편

### 3주차 (8/15~8/21) — 데이터 기반 선별 집중

- 첫 실데이터 확보 구간. 애드센스 리포트에서 **페이지별 RPM** 확인
- 상위 20% 글의 공통점 추출 → 그 패턴으로만 발행 (여기서 효율이 2~3배 갈립니다)
- 성과 없는 니치 과감히 축소, 잘 되는 니치에 발행량 몰기
- 광고 배치 A/B 테스트: 본문 상단 / 첫 문단 후 / 목차 하단 위치별 RPM 비교
- 목표: 누적 200~260편

### 4주차 (8/22~8/31) — 수확 + 9월 구조 세팅

- 상위노출 진입한 글 리라이팅/보강 (기존 글 개선이 신규 발행보다 ROI 높은 구간)
- 내부링크 구조 정비 (체류시간·PV/세션 상승 → RPM 상승)
- 9월 이후 구조 착수: 워드프레스 D 본격화, 언론사 경로 검토 ([05](05-단기달성-대안경로.md))
- 8/31 최종 집계 및 9월 계획 확정
- 목표: 누적 300~380편

이 표의 4주차 ₩150만이 성실 실행 시의 중앙값 기대치입니다. 디스커버가 터지면 여기서 3~5배가 나올 수 있지만 재현 가능한 계획으로 잡으면 안 됩니다.

## 8월 안에 현금이 들어오게 하려면

애드센스 8월 수익은 9월 하순 입금이라 8월 내 입금이 불가능합니다. 8월 중 실입금을 만들려면:
- **쿠팡파트너스**: 8월 수익 → 9월 15일경 입금 (그래도 8월은 아님)
- 즉 **어떤 정상적 제휴 프로그램도 8월 활동분이 8월에 입금되지 않습니다.** "8월 31일까지 월 1,000만원"이 입금 기준이라면 목표 정의 자체를 run-rate 기준으로 바꾸셔야 합니다.
