# 02. 31일 실행계획 (2026-08-01 ~ 08-31)

목표: **8월 말 시점 월 run-rate ₩10,000,000**
전략 근거: [06-핵심플레이북.md](06-핵심플레이북.md) — 이슈 파생 키워드 + 네이버 홈판

512편 분석 후 1차 계획에서 바뀐 것:
- 구글 디스커버 → **네이버 홈판**으로 최대 레버 교체 (한국 시장 실측 근거)
- 네이버 블로그(N)를 **트래픽 엔진**으로 편입. 애드센스 4개(A·B·C·D)는 유지
- 발행량 상향: 하루 8~12편 → **12~19편**
- B(이슈) 비중 최대화 — 파생 키워드는 타율 게임이라 시도 횟수가 곧 수익

## 자산 구조

```
        N: 네이버 블로그 (홈판 엔진, 하루 10만 유입 노림)
                    │  확장 정보 링크
        ┌───────────┼───────────┬───────────┐
        ▼           ▼           ▼           ▼
   A 고단가      B 이슈파생    C 커머스    D 워드프레스
   (티스토리)    (티스토리)   (티스토리)   (자체도메인)
   애드센스      애드센스   쿠팡+애드센스   애드센스
```

| 블로그 | 주제 | 일 발행 | 8/31 누적 |
|---|---|---|---|
| N | 생활밀착 이슈 (네이버) | 2~3 | 70~90 |
| A | 금융/보험/세금/정책 | 2~3 | 70~90 |
| B | 실시간 이슈 파생 | 5~8 | 180~250 |
| C | 제품 비교·구매가이드 | 2~3 | 70~90 |
| D | 에버그린 정보 | 1~2 | 40~60 |

## 1주차 (8/1~8/7) — 인프라 + 홈판 첫 시도

### 8/1 (오늘) — 최우선

1. **애드센스 지급 요건 점검** ← 이게 안 되면 다 무의미합니다
   - [ ] 주소 PIN 인증 완료 여부
   - [ ] 세금정보(W-8BEN) 제출
   - [ ] 지급수단 등록, 예금주명 일치
2. 기존 승인 블로그를 A/B/C 중 무엇으로 쓸지 결정 (기존 주제와 가장 가까운 것)
3. 티스토리 블로그 추가 개설 (계정당 5개 가능 → A·B·C 커버)
4. **네이버 블로그 N 개설** — 주제 하나로 고정. 잡블로그는 홈판 추천에서 탈락
5. 애드센스 → 사이트 추가, ads.txt 설정
6. 쿠팡파트너스 가입 신청 (승인 며칠 소요)

### 8/2~8/3 — 세팅

- 스킨/레이아웃, 광고 유닛 배치 ([03](03-키워드-수익구조.md))
- 서치콘솔 + 네이버 서치어드바이저 + 빙 웹마스터 등록, 사이트맵/RSS 제출
- 워드프레스 D: 도메인 구매, 호스팅, 테마
- **일일 루틴 시작** — 아침 이슈 스캔부터 즉시 가동. 세팅 끝나고 시작하면 늦습니다

### 8/4~8/7 — 발행 본격화

- 목표: 누적 80~120편

## 2주차 (8/8~8/14) — 홈판 판가름

- 색인 상태 점검. 미색인 글은 서치콘솔 URL 검사로 개별 요청
- 파생 키워드 타율 측정 — 발행 10편 중 몇 편이 1페이지 진입했는지
- C: 쿠팡파트너스 승인되면 즉시 링크 삽입 (고지 문구 필수)
- 목표: 누적 200~280편

### 8/14 — 의사결정 게이트 ★

**N 블로그 홈판 노출이 한 번이라도 나왔는가?**

- **YES** → 노출된 글의 주제·이미지·발행시간·길이를 패턴화. N 발행량을 하루 5편으로 증량. 이게 1,000만원 경로입니다
- **NO** → 주제 전면 교체. 홈판은 생활밀착 실용 정보가 강합니다. 이미지 규격(가로형 고화질, 텍스트 최소)과 발행 시간대를 바꿔서 재시도. 3주차에도 안 나오면 홈판은 포기하고 B(이슈 파생) 물량으로 전환
