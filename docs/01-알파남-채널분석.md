## 조사 방법과 한계 (먼저 밝힙니다)

**채널의 "모든 영상"을 전수 파악하지는 못했습니다.** YouTube가 자동화된 페이지 요청에 캡차/봇 차단(HTTP 302 → google.com/sorry)을 걸어서, 채널 영상 목록 페이지와 개별 영상 페이지 본문·자막을 가져오지 못했습니다. RSS 피드도 404였습니다.

대신 확보한 것:
- 검색으로 수집한 개별 영상 제목 다수
- **채널 운영자의 유료 강의 전체 커리큘럼 19강** (Coloso) — 영상보다 오히려 방법론이 더 구체적으로 정리된 1차 자료
- 유료 교육 사이트(애드센스팜) 본문의 전략 설명 및 단계별 수익 목표표
- 제3자 비평/논란 자료

영상 나열보다 이 커리큘럼이 "비책"의 실체에 훨씬 가깝다고 판단해 그쪽을 중심으로 정리했습니다.

## 확인된 영상 제목 (일부)

- "블로그로 현금 60억 ㄷㄷ '블로그 예전처럼 하지마세요, 돈 쓸어담게해준 방법 공개합니다' 92년생 천재 블로거 알파남"
- "5년동안 블로그에 글쓰고 통장에 17억 모은 92년생 디지털농사꾼"
- "'한국인만 몰라서 못해요' 전세계 1등 부업으로 통장에 75억 모은 미친 92년생 재택 부업"
- "'한국인만 몰라요' 65세 엄마가 하루 2,000달러 버는 기적의 전세계 1등 부업"
- "'상상도 못한 방법으로 돈 법니다' 블루오션 틈새시장 찾아 4년 만에 56억 번 MZ대표님ㅣ재택 부업 추천"
- "티스토리 애드센스의 찐현실 // 월 1000만원 벌어도 90% 포기하는 진짜 이유"

**패턴이 보입니다.** 동일 인물의 누적 수익이 영상마다 17억 → 52억 → 56억 → 60억 → 75억으로 다릅니다. 제목 형식도 전형적인 클릭 유도형(금액 + 나이 + "한국인만 몰라요")입니다. 채널의 1차 수익 모델은 블로그 애드센스가 아니라 **강의·전자책 판매**이고, 영상은 그 세일즈 퍼널의 입구입니다. 이걸 감안하고 내용을 취사선택해야 합니다.

## 강의 커리큘럼 (19강) — 실제 방법론

| 구간 | 내용 |
|---|---|
| 1~5강 | 온라인 수익화 기초, 애드센스 구조, 블로깅 효율 도구 세팅, ChatGPT 실전 활용 5가지, 블로그 자동화용 커스텀 GPT 제작 |
| 6~9강 | 티스토리 최적화 설정, AI로 애드센스 승인 신청, 도메인 연결 및 승인 제출, 검색엔진 등록·색인 |
| 10~15강 | 수익형 운영과 키워드 선정, 하루 수백만원 사례, **네이버 지식iN 트래픽 전략**, 최적 광고 배치, 원페이지 레이아웃 수익 극대화 |
| 16~19강 | 워드프레스 애드센스, 멀티플랫폼 확장, **월 1,000만원 39단계 로드맵**, 지속을 위한 마인드셋 |

핵심 전략으로 강조되는 것:
- 조회수가 아니라 **돈이 되는 키워드** (행동 유도형, 40대 이상 검색, 광고 단가 높은 것)
- 경쟁 낮고 광고가치 높은 "골든 키워드" 발굴
- 4년 테스트 기반 **광고 유닛 배치 최적화**
- 애드센스 승인 전 **네이버 애드포스트 + 쿠팡파트너스**로 초기 수익
- 티스토리 → 워드프레스 → 유튜브 멀티플랫폼 확장

## 채널이 스스로 제시하는 수익 타임라인 ← 가장 중요한 부분

운영자 본인 기록:
- 1개월차 300만원 → 2개월차 500만원 → **3개월차 월 1,000만원**

수강생 성과표:
- 1~3개월: 월 20~50만원 (네이버+쿠팡 병행)
- 3~6개월: 월 50~100만원 (애드센스 승인 후)
- 6개월 이후: 월 100~300만원 (전 채널 결합)
- 별도 문구: "3개월 열심히 한 수강생 87%가 월 100만원 달성"

**이 채널조차 1개월 만에 월 1,000만원을 주장하지 않습니다.** 본인 최고 기록이 3개월이고, 수강생 기준으로는 6개월 이후에도 월 100~300만원입니다. 즉 이번 목표(31일 내 1,000만원)는 **참고하라고 지정하신 채널의 자체 데이터와도 정면으로 충돌합니다.** [00-현실점검.md](00-현실점검.md)의 결론과 같은 방향입니다.

## 논란 — 방법론 채택 전에 알아야 할 것

- 실제 수익의 대부분이 **블로그가 아니라 언론사(인터넷신문) 운영**에서 나왔다는 지적이 반복적으로 제기됩니다. 정작 강의에서 언론사 파트 비중은 작으면서 290만원짜리 강의를 판매한다는 비판.
- 반박 측: 강의에 언론사 등록·운영·보수·솔루션까지 포함돼 있다는 수강생 주장도 존재.
- 커뮤니티 여론: "티스토리 끝났다", "2026년은 너무 늦었다"는 회의론과 "나도 월 1,200달러 찍었다"는 긍정론이 공존.

4. 쿠팡파트너스 병행 — **애드센스보다 정산이 빠르고 8월 내 실입금이 가능한 유일한 수단**
5. 티스토리 → 워드프레스 확장으로 플랫폼 리스크 분산
6. 언론사 경로는 9월 이후를 위해 8월에 착수 검토 → [05](05-단기달성-대안경로.md)

**폐기:**
1. 수익 인증 숫자 전반 — 검증 불가하고 영상마다 불일치
2. 네이버 지식iN 트래픽 전략 — 자문자답/링크 살포는 네이버 운영정책 위반이고 계정 정지 리스크. 사용자께서 요구하신 "사람들에게 피해를 주지 않으며" 조건에도 어긋납니다.
3. 1개월 만에 월 1,000만원이라는 기대치 — 채널 자체 데이터가 3개월입니다

## 후속 조사가 필요하면

전 영상 전수 분석이 꼭 필요하면 캡차를 우회하지 않는 합법적 방법이 있습니다:
- YouTube Data API v3 키 발급 → `playlistItems.list`로 전체 업로드 목록 취득
- 자막은 `captions` API 또는 각 영상 페이지 수동 확인

API 키를 주시면 전 영상 목록·조회수·설명을 정식으로 뽑아 이 문서를 갱신하겠습니다.
