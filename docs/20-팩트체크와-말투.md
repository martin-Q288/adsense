# 20. 팩트체크와 말투 — 발행 전에 반드시 거치는 두 관문

2026-08-04. 실제로 오류가 나와서 만든 문서.

## 1. 왜 이 문서가 필요한가 — 실제로 틀렸다

광복절 원고에 이렇게 썼었다.

> 추석 역시 연휴 마지막 날인 9월 26일이 토요일이라 9월 28일 월요일이
> 대체공휴일입니다. **9월 24일 목요일부터 28일 월요일까지 닷새**를 쉽니다.

**전부 틀렸다.** 2026년 추석에는 대체공휴일이 없다. 9월 24일(목)~27일(일)
나흘이고 28일 월요일은 평일이다.

더 나쁜 건 **그럴듯한 논리로 감싸서 썼다는 것**이다. "토요일이라 대체공휴일"
이라는 규칙을 광복절에서 가져와 추석에 그대로 적용했는데, 두 제도는 규칙이
다르다. 광복절은 토·일 모두 대체 대상이고, 설날·추석 연휴는 **일요일과
겹칠 때만** 대체가 붙는다.

**숫자 하나가 틀린 게 아니라 원리를 지어냈다.** 이게 가장 위험한 형태다.

### 구조적 원인

내 지식 기준일은 2026년 5월인데 원고는 8월 기준으로 쓴다. 즉 **2024~2025년
값을 기억해서 2026년으로 적을 수 있다.** 그럴듯하게. YMYL 주제에서 이러면
순위가 아니라 블로그가 위험하다.

## 2. 팩트체크 규칙

### 2-1. 무조건 검색해야 하는 것

아래는 예외 없이 발행 전에 웹 검색으로 확인한다. 기억에 의존하지 않는다.

- [ ] **날짜** — 공휴일, 연휴, 절기, 마감일, 시행일
- [ ] **금액** — 상한액·하한액, 단가, 수수료, 한도, 지급액
- [ ] **기준선** — 소득요건, 재산요건, 면적, 인원수
- [ ] **전화번호·URL**
- [ ] **제도 시행 시점과 조건** — "언제부터", "누구에게"
- [ ] **요일** — 날짜가 나오면 요일도 확인. 계산으로 때우지 않는다

### 2-2. 검증 강도

| 위험도 | 대상 | 검증 |
|---|---|---|
| 최상 | 금액·날짜·법적 요건 | **출처 2개 이상**. 가능하면 공식 기관 |
| 상 | 제도 절차, 신청 방법 | 검색 1회 + 공식 사이트 확인 |
| 중 | 시세, 가격대 | 범위로 쓰고 조회처를 본문에 명시 |
| 하 | 일반 상식 | 그대로 쓰되 단정하지 않음 |

### 2-3. 확인이 안 되면

**지어내지 않는다.** 셋 중 하나를 택한다.

1. 그 문장을 뺀다
2. 범위로 바꾸고 조회처를 적는다 — "서울 기준 1만 7천~2만 원 선.
   정확한 시세는 한국소비자원 참가격(price.go.kr)에서 확인"
3. 기준이 아님을 밝힌다 — "이 70~80%는 법에 정해진 숫자가 아니라
   업계에서 통용되는 안전선이에요"

### 2-4. 원고에 남기는 기록

프런트매터에 `팩트체크` 항목을 만들고 **무엇을 무엇으로 확인했는지** 적는다.

```yaml
팩트체크: 2026-08-04 웹 검증 완료
  · 등기부 열람 700원 / 발급 1,000원 (인터넷등기소)
  · 미납국세 열람 — 보증금 1천만원 초과 + 임대차 시작일까지 동의 불요,
    임대인에게 통보됨
  · 70~80%는 법정 기준이 아니라 통용되는 안전선. 본문에 그렇게 명시함
```

이 칸이 비어 있으면 발행하지 않는다.

## 3. 말투 규칙

### 3-1. 목표

**실제 한국 사람이 쓴 것처럼 자연스럽고, 쉽고, 편안하게.**
공문서도 아니고 논문도 아니다. 아는 사람이 옆에서 알려주는 톤이다.

### 3-2. 기본은 해요체, 무게가 필요할 때만 합니다체

전부 해요체면 가볍고, 전부 합니다체면 딱딱하다. **섞는다.**

- 설명·안내 → 해요체 "확인해 보세요", "이거 하나는 꼭 하세요"
- 경고·핵심 단정 → 합니다체 "2천만 원이 그냥 사라집니다"
- 법령 인용, 고지 → 합니다체

### 3-3. 걷어낼 표현

| 딱딱함 | 자연스러움 |
|---|---|
| 확인하시기 바랍니다 | 확인해 보세요 |
| ~하는 편이 좋습니다 | ~하는 게 좋아요 |
| ~할 수 있습니다 (반복) | ~하실 수 있어요 / ~하면 돼요 |
| 필요합니다 | 있어야 해요 |
| ~해야 합니다 (반복) | ~하셔야 해요 |
| 상기 / 하기 / 해당 | 위 / 아래 / 그 |

### 3-4. 자연스럽게 만드는 장치

- **독자에게 말 걸기** — "부동산에서 '오늘 가계약금 넣으셔야 한다'는 말
  들으셨나요?"
- **짧은 문장 끼우기** — "이거 모르는 분이 정말 많아요."
- **이유를 먼저 대기** — "왜 하필 70~80%냐면요,"
- **1인칭 예시** — "저한테 남는 건 1억 8천이에요"
- **부담 덜어주기** — "부담되면 안 하셔도 됩니다"

### 3-5. 하지 말 것

- 억지 친근함 — "~했답니다", "~이지요", 과도한 이모지
- 과장 — "충격", "미쳤다", "반드시 알아야 할"
- 근거 없는 단정 — 확인 안 된 걸 해요체로 부드럽게 말하면 더 위험하다

## 4. 발행 전 최종 체크

```
[ ] 팩트체크 칸을 채웠는가. 날짜·금액·요일을 검색으로 확인했는가
[ ] 확인 못 한 수치를 그대로 두지 않았는가
[ ] 제도 원리를 다른 제도에서 유추해 지어내지 않았는가
[ ] 해요체와 합니다체가 섞여 있는가
[ ] "확인하시기 바랍니다" 류 공문서 투가 남아 있는가
[ ] 소리 내어 한 문단 읽었을 때 어색하지 않은가
```

마지막 항목이 제일 확실하다. 읽어서 걸리면 독자도 걸린다.
