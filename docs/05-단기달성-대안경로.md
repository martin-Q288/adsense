# 05. 31일 안에 월 1,000만원에 실제로 도달하는 경로

[00-현실점검.md](00-현실점검.md)에서 "신규 블로그 4개로는 불가능"이라고 결론냈습니다. 그럼에도 31일이라는 기한이 고정이라면, 남는 선택지는 **블로그를 키우는 게 아닌 것들**뿐입니다. 정직하게 셋 다 적습니다.

---

## 경로 1. 수익 사이트 매입 (사이트 플리핑) — 유일하게 31일 내 가능

이미 월 1,000만원이 나오는 사이트를 사면 됩니다. 이건 실제로 8월 안에 가능합니다.

**시세**: 애드센스 수익 사이트는 통상 **월순수익의 20~40배**에 거래됩니다.
- 월 1,000만원 사이트 → **2억 ~ 4억원**
- 월 250만원 사이트 4개로 분산 매입 → 총 2~4억, 리스크 분산 측면에서 더 유리

**거래처**
- 국내: 사이트 매매 전문 카페/커뮤니티, 코드너리·플리핑 관련 중개
- 해외: Flippa, Empire Flippers, Motion Invest (영문 사이트, 달러 수익 → 환율 이점)

**필수 실사 항목** — 이거 안 하면 사기당합니다
- 애드센스 계정 **화면 공유 실시간 확인** (스크린샷은 위조됩니다)
- 서치콘솔 원본 데이터 — 트래픽 출처가 검색인지, 직접유입(=구매 트래픽 의심)인지
- 최근 12개월 수익 추이 — 하락 중인 사이트를 고점에 파는 게 이 시장의 기본 패턴입니다
- 백링크 프로필 (Ahrefs/Semrush) — 구매 링크가 많으면 향후 수동조치 폭탄
- 콘텐츠 표절 검사
- 사이트 소유권 이전 방식 (도메인 + 호스팅 + 콘텐츠), **애드센스 계정은 양도 불가** — 내 계정으로 재연결해야 하고 이 과정에서 수익이 변동할 수 있음

**리스크**: 인수 직후 수익이 30~50% 빠지는 경우가 흔합니다. 매도자의 운영 노하우가 안 따라오기 때문입니다. 2~4억을 태울 각오가 없으면 권하지 않습니다.

**판단**: 자본이 있으면 이게 답입니다. 없으면 이 경로는 닫힙니다.

## 경로 2. 언론사(인터넷신문) 등록 — 알파남 실제 수익의 정체, 다만 31일엔 불가

조사 결과 반복적으로 제기되는 지적: **알파남 실제 수익의 대부분은 블로그가 아니라 언론사 운영에서 나왔다.**

왜 언론사가 압도적으로 유리한가:
- **네이버 뉴스 검색제휴**에 들어가면 네이버 검색 트래픽을 블로그와 비교 불가한 규모로 받습니다
- 구글 뉴스/디스커버 노출에서 언론사 도메인이 구조적으로 유리합니다
- 기사 형식은 대량 발행이 자연스럽습니다 (블로그의 대량 발행은 스팸으로 보이지만 언론사는 정상)

**절차와 소요 기간**
1. 인터넷신문 등록 — 관할 시·도청. 발행인·편집인 요건, 취재인력 3인 이상(발행인·편집인 포함 가능) 등 요건 충족 필요. **등록 자체는 수 주**
2. 사이트 구축 (기사 CMS) — 전문 업체 이용 시 수 주, 비용 수백만원대
3. **네이버 뉴스제휴 평가** — 뉴스제휴평가위원회 심사. 신청 시기가 정해져 있고 심사에 **수개월**. 통과율도 낮습니다
4. 구글 뉴스 등록 — 상대적으로 빠름 (수 주)

**결론: 31일 안에는 불가능합니다.** 하지만 9~12월에 월 1,000만원을 진지하게 노린다면 **8월에 착수해야 하는 경로**입니다. 등록과 심사가 오래 걸리기 때문에 시작이 빠를수록 좋습니다.

**주의**: 언론사 등록 후 기사 형식만 빌린 광고성 콘텐츠를 대량 발행하는 건 유사언론 행위로 문제가 될 수 있고, 사용자님의 "사람들에게 피해를 주지 않으며" 조건에도 걸립니다. 실제로 정보 가치가 있는 기사를 발행하는 구조여야 합니다.

## 경로 3. 목표 재정의 — 가장 권하는 선택

"8월 31일까지 월 1,000만원"을 아래 중 하나로 바꾸는 것입니다.

**3-A. 기한 연장**: 8월 → 12월 (5개월). 참고하신 채널 본인 기록이 3개월, 수강생 기준 6개월 이후 월 100~300만원입니다. **5개월에 월 1,000만원도 여전히 상위 몇 %의 결과**지만, 최소한 물리적으로 가능한 범위 안에 있습니다.

**3-B. 8월 목표를 자산 지표로 전환**:
- 발행 글 340편
- 색인 글 270편
- 상위 10위 이내 키워드 30개
- 월 run-rate ₩150만
- 9월 확장 구조(워드프레스 + 언론사 등록 착수) 완료

**3-C. 수익원 확장**: 애드센스 단독으로 월 1,000만원은 트래픽 요구량이 너무 큽니다. 같은 트래픽에서 훨씬 큰 돈이 나오는 건:
- 제휴마케팅 고단가 상품 (보험·대출 DB 제휴는 건당 수만원)
- 자체 전자책/강의 — 아이러니하게도 알파남 본인의 실제 주력 수익모델입니다. 블로그를 리드 수집 채널로 쓰는 구조
- 협찬·기자단

트래픽 1만 PV의 가치: 애드센스 ₩2만 / 쿠팡파트너스 ₩5~15만 / 고단가 제휴 ₩30~100만 / 자체 상품 ₩100만+

**월 1,000만원까지의 거리를 좁히는 가장 빠른 방법은 트래픽을 늘리는 게 아니라 PV당 수익을 늘리는 것입니다.**

## 권고

1. **8월**: [02-31일-실행계획.md](02-31일-실행계획.md) 그대로 실행. 목표는 run-rate ₩150만 + 자산 구축. 동시에 언론사 등록 착수
2. **9~10월**: 워드프레스 본격화, 고단가 제휴 도입, 언론사 사이트 오픈
3. **11~12월**: 네이버 뉴스제휴 신청, 자체 상품 라인 추가 → 이 시점에 월 1,000만원이 사정권
4. **자본이 2~4억 있다면**: 경로 1을 병행. 이것만이 8월 내 달성 가능한 유일한 길입니다
