# 04. 계정 보호 — 이걸 어기면 프로젝트 전체가 0원입니다

"수단과 방법을 가리지 않고"라고 하셨지만, 아래 항목들은 도덕 문제 이전에 **수익 관점에서 자살행위**입니다. 애드센스 계정 정지는 대부분 영구이고, 정지되면 **미지급 수익도 전액 몰수**됩니다. 8월 내내 쌓은 수익이 그대로 0원이 됩니다. 그리고 한 번 정지된 사람과 연결된 신규 계정도 대부분 재정지됩니다.

승인된 계정 1개가 이 프로젝트의 유일한 자산입니다. 이걸 지키는 게 최우선순위입니다.

## 즉시 영구정지 사유

| 행위 | 결과 |
|---|---|
| 자기 광고 클릭 (VPN·다른 기기 포함) | 구글은 IP뿐 아니라 기기 지문·행동 패턴으로 탐지합니다. 예외 없이 적발됩니다 |
| 지인/품앗이 클릭 교환 | 클릭 패턴 이상치로 탐지. 관련 계정 전체 정지 |
| 트래픽 구매 (봇/유입 서비스) | 무효 트래픽. 판매자가 "안전하다"고 해도 100% 적발됩니다 |
| "광고를 클릭해주세요" 유도 문구 | 명시적 정책 위반 |
| 광고를 콘텐츠/버튼처럼 위장 | 기만적 배치 |
| 자동 리다이렉트·팝업 강제 | 정책 위반 |

**무효 트래픽은 사용자님이 "사람들에게 피해를 주지 않으며"라고 하신 조건에도 정면으로 어긋납니다.** 광고주가 아무 가치 없는 클릭에 돈을 내게 되는 구조라서요.

## 색인 삭제 / 저품질 판정 사유

| 행위 | 결과 |
|---|---|
| 타 사이트 글 복사·짜깁기 | 저작권 침해 + 중복 콘텐츠. 법적 리스크까지 |
| AI 무편집 대량 발행 | scaled content abuse. 사이트 단위 색인 삭제 |
| 키워드 스터핑 | 순위 하락 |
| 링크 구매·사설 링크팜 | 링크 스팸. 수동 조치 |
| 만료 도메인 남용 | 순위 조작 |
| 지식iN 자문자답 / 커뮤니티 링크 살포 | 네이버 운영정책 위반, 계정 정지. 참고 채널이 가르치는 항목이지만 채택하지 않습니다 |

## 안전 운영 체크리스트

- [ ] 애드센스 주소 PIN 인증 완료
- [ ] 세금정보(W-8BEN) 제출 완료
- [ ] 지급수단(은행계좌) 등록 및 예금주명 일치 확인
- [ ] 각 블로그 ads.txt 설정
- [ ] 개인정보처리방침 페이지 (애드센스 필수 요건)
- [ ] 쿠팡파트너스 수수료 고지 문구 (표시광고법 의무)
- [ ] 모든 이미지 저작권 확인 (직접촬영/무료스톡/AI생성)
- [ ] 자신의 블로그 방문 시 애널리틱스 내부 IP 제외 설정
- [ ] 애드센스 리포트 주 1회 확인 — 이상 클릭률(CTR 10% 초과) 감지 시 즉시 정책센터 확인

## 공격받았을 때 (악의적 클릭 폭탄)

경쟁자가 고의로 광고를 반복 클릭해 내 계정을 정지시키려는 공격이 실제로 있습니다.

- 애드센스는 대부분 자동으로 필터링합니다. 수익에서 차감되지만 정지까지는 잘 안 갑니다
- 이상 패턴 발견 시 **무효 클릭 신고 양식**으로 선제 신고하세요. 신고 이력이 있으면 정지 판단에서 유리합니다
- 로그로 해당 IP 확인 → 광고 게재 차단 목록에 추가

## 요약

31일 안에 최대한 공격적으로 가되, **계정을 태우는 행위만은 절대 하지 않습니다.** 이건 윤리 조언이 아니라 손익 계산입니다. 위 항목 중 하나라도 하면 기대수익이 마이너스가 됩니다.
