# 19. 하루 몇 개까지 써도 되나 — 저품질 리스크

2026-08-04. 자료 '7_2 티스토리 저품질 통누락 펍벤 완벽 대응 매뉴얼' 확인 후 정리.

## 1. 공식 기준은 없다

먼저 분명히 해둘 것. **다음·카카오는 발행 개수 상한을 공개한 적이 없다.**
블로거들 사이에 도는 "하루 3개까지", "5개 넘으면 봇 판정" 같은 숫자는
근거가 없다. 자료의 저품질 사유 목록에도 발행 개수는 들어 있지 않다.

자료가 밝힌 실제 제재 사유는 이것이다.

- 경쟁자의 프로그램을 이용한 비정상 접근·공격
- 타인의 악의적인 신고 누적
- 과도한 이미지 내 키워드 반복
- **병원·건강·대출·보험 등 고단가 키워드로 인한 신고**
- 유튜버가 배포한 스킨 내 코드 오류
- 고정 광고, 플로팅 광고, 자동 리디렉션
- 오퍼월(Offerwall) 광고

즉 **개수가 아니라 신고와 코드가 블로그를 죽인다.**

## 2. 그런데도 개수를 조절해야 하는 이유 세 가지

**첫째, 급변이 신호가 된다.**
우리 블로그는 15개월 휴면 상태다(docs/16). 15개월 조용하다가 갑자기 하루
5편이 쏟아지면, 개수와 무관하게 패턴 자체가 비정상으로 읽힌다. 자료가
"경쟁자의 프로그램을 이용한 비정상적인 접근"을 사유로 든 것과 같은 층위다.

**둘째, 고단가 편중이 신고를 부른다.**
자료가 명시한 사유다. 대출·보험·부동산 글을 하루에 몰아 올리면 같은
키워드로 먹고사는 사람들 눈에 띈다. **신고 한 건이면 수동 검토로 넘어간다.**
8월 전세 8부작(docs/18)이 정확히 이 위험 구간에 있다.

**셋째, 색인이 못 따라온다.**
휴면 블로그는 크롤러 방문 주기가 길다. 하루 5편을 써도 다음·구글이 그날
다 가져가지 않는다. 색인 안 된 글은 그날치 재고일 뿐이고, 시의성 원고라면
마감을 넘겨 값이 사라진다.

## 3. 우리가 쓰는 값

공식 기준이 아니라 **"휴면 뒤 급변을 만들지 않는다"**는 원칙에서 나온 값이다.

| 구간 | 하루 편수 | 이유 |
|---|---|---|
| 1~7일차 | 1편 | 크롤러가 돌아올 시간을 준다 |
| 8~14일차 | 2편 | 색인이 붙는 걸 확인하고 올린다 |
| 15일차부터 | 3편 | 상한. 더 늘리지 않는다 |

- **발행 간격 최소 3시간** — 09:00 / 13:00 / 19:00
- **고단가 뒤에는 생활정보를 끼운다.** 대출·보험·부동산 글이 연달아 나가지
  않게 한다
- **예약발행으로 몰아 올리지 않는다.** 새벽에 5편이 한꺼번에 올라가는 패턴이
  가장 위험하다

`python3 tools/pipeline.py plan` 이 이 규칙대로 일정을 짜준다. 고단가가
연속으로 붙은 날이 있으면 경고를 낸다.

## 4. 개수보다 훨씬 중요한 것

자료 기준으로 블로그를 실제로 죽이는 건 따로 있다. 발행량을 아무리 조절해도
아래를 어기면 소용없다.

- [ ] **펍벤 코드를 절대 넣지 않는다.** 저품질 평가를 받은 애드센스 계정의
      광고 코드를 넣으면 발행과 동시에 검색에서 누락된다. 코드를 빼도
      복구가 거의 안 된다
- [ ] **플로팅·고정 광고, 자동 리디렉션, 오퍼월을 넣지 않는다.**
      우리는 티스토리 자동광고만 쓴다(docs/08)
- [ ] **출처 불명 스킨을 쓰지 않는다.** 유튜버 배포 스킨의 코드 오류가
      사유 목록에 있다
- [ ] **이미지 안에 키워드를 반복해 박지 않는다.** 썸네일 문구는
      제목 수준으로만
- [ ] **계정과 블로그를 한 곳에 몰지 않는다.** 자료의 마지막 조언이다

## 5. 사고가 났을 때

증상별로 대응이 다르다. 자료 기준.

| 증상 | 대응 |
|---|---|
| 저품질·통누락 | 카카오톡 고객센터 1:1 문의. **이메일보다 성공률이 높다.** 복구 사례 있음 |
| 로그인 제한 | 1차 7일 → 2차 30일 → 3차 영구. 재심사 복구 사례가 드물다 |
| 펍벤 | 코드 교체해도 복구 어려움. 예방만이 답 |
| 접근 제한 | 도메인만 떼어 다른 블로그에 연결. 트래픽·신뢰도는 유지된다 |

문의할 때는 블로그 주소, 증상, 콘텐츠 정리 여부, 외부 공격·신고 가능성을
같이 적는다. 자료에 문의문 예시가 있다.

## 6. 목표와의 충돌은 인정하고 간다

하루 1~3편 램프로 8월에 나갈 수 있는 원고는 최대 50편 안팎이다.
**이 물량으로 8월 안에 월 1,000만원은 나오지 않는다.** 색인에만 2~4주가
걸리고, 자료도 SEO 효과는 최소 3개월이라고 못박는다(docs/07).

그렇다고 물량을 밀어붙이면 블로그가 죽는다. 죽으면 0원이다.
**8월은 축을 세우는 달로 잡고, 램프를 지키는 쪽이 기댓값이 높다.**
현실적인 목표선은 docs/00에서 다시 계산한다.
