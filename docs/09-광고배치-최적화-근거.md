# 09. 광고 배치 최적화 — 데이터와 근거

배치를 감으로 정하면 안 됩니다. 아래는 조사한 성과 데이터와, 거기서 도출한 배치도입니다.

## 1. 핵심 발견 5가지

### 1-1. 수익을 결정하는 1번 변수는 위치가 아니라 **가시성(Viewability)**

- 애드센스 Active View 기준: **광고 면적의 50% 이상이 1초 이상 화면에 보여야** 조회 가능 노출로 집계
- 가시성과 RPM은 양의 상관관계. **평균 가시성이 50% 미만이면 고단가 캠페인이 아예 내 사이트를 타깃하지 않습니다**
- 즉 광고를 아무리 많이 붙여도 안 보이는 자리면 0원입니다

**이게 가장 중요합니다.** 광고 개수를 늘리는 것보다 이미 있는 광고의 가시성을 50% 위로 올리는 게 수익에 더 큽니다.

### 1-2. 본문 삽입(In-content)이 가장 강력한 자리

- 콘텐츠 중심 블로그에서 **in-content가 최고 성과 배치**
- 최적 위치: **2~3번째 문단 직후**
- 최적 밀도: **300~500단어마다 1개**
- "본문 시작 전"과 "2문단 직후"가 가장 높은 참여를 만듭니다

### 1-3. 336×280이 300×250보다 eCPM이 5~15% 높다

| 사이즈 | 특징 |
|---|---|
| **336×280** | 300×250 대비 캔버스 20% 넓음. **eCPM 5~15% 높음** |
| 300×250 | 모바일 본문에서 최고 성과 |
| 320×100 | 모바일 앵커. 대형 모바일 배너 |
| 320×50 | 모바일 앵커 소형 |
| 728×90 | 데스크톱 상단/하단 |

**반응형 단위를 쓰되 336×280이 나올 수 있는 폭을 확보**하는 게 핵심입니다. 본문 컨테이너가 336px보다 좁으면 300×250으로 떨어집니다.

### 1-4. 사이드바는 데스크톱에서만 유효

- **고정(sticky) 사이드바가 데스크톱 애드센스 수익의 15~25%** 를 차지
- 그러나 2026년 기준 **트래픽의 80% 이상이 모바일**
- 모바일에서 사이드바는 무의미하고 레이아웃만 깨뜨립니다

→ 데스크톱엔 sticky 사이드바, 모바일엔 앵커. 둘을 분리해야 합니다.

### 1-5. 지연 로딩(Lazy load)은 양날의 검

- 제대로 쓰면 가시성 비율이 올라갑니다 (안 보이는 광고를 요청하지 않으므로)
- 그러나 **스크롤이 적은 페이지에서는 광고가 아예 로드되지 않아 노출·수익이 0**이 됩니다

→ **상단 2개 광고는 지연 로딩하지 말 것.** 하단 광고만 적용.

## 2. 도출한 배치도

본문 1,500~2,500자 기준입니다.

```
┌─────────────────────────────────┐
│ 제목                             │
│ 결론 박스 (핵심 답 + 요약)         │ ← 먼저 답을 줘서 이탈 방지
├─────────────────────────────────┤
│ ★ AD 1  in-content 336×280      │ ← 가시성 최상 구간
│         (지연로딩 X)              │    독자가 결론 읽고 목차 보는 사이
├─────────────────────────────────┤
│ 목차                             │ ← 스크롤 깊이 상승
├─────────────────────────────────┤
│ H2 섹션 1                        │
│ H2 섹션 2                        │
├─────────────────────────────────┤
│ ★ AD 2  in-content 336×280      │ ← 약 300~500단어 지점
│         (지연로딩 X)              │
├─────────────────────────────────┤
│ H2 섹션 3                        │
│ H2 섹션 4                        │
├─────────────────────────────────┤
│ ★ AD 3  in-content              │ ← 약 300~500단어 지점
├─────────────────────────────────┤
│ H2 섹션 5, 6                     │
├─────────────────────────────────┤
│ ★ AD 4  in-content              │ ← 완독 구간. 이탈률 낮아 품질 좋음
├─────────────────────────────────┤
│ H2 자주 묻는 질문                 │
├─────────────────────────────────┤
│ 관련 글 내부링크 3~5개            │ ← 클릭 시 전면광고 자연 노출
│                                  │   위아래를 광고로 막지 않음
├─────────────────────────────────┤
│ ★ AD 5  멀티플렉스               │ ← 세션당 PV 상승
└─────────────────────────────────┘

  [별도] 데스크톱 sticky 사이드바  ← 스킨에 삽입 (데스크톱 수익 15~25%)
  [별도] 모바일 앵커 320×100      ← 자동광고 설정에서 ON
  [별도] 전면광고 Vignette         ← 자동광고 설정에서 ON
```

### 왜 AD 1을 결론 박스 **뒤**, 목차 **앞**에 두는가

- 제목 바로 아래에 두면 독자가 답을 보기 전에 광고를 만나 이탈합니다
- 결론을 먼저 읽히면 "이 글이 답을 준다"는 신호가 생겨 스크롤이 이어집니다
- 결론 → 목차 사이는 독자가 반드시 지나가면서 **잠깐 멈추는 구간**이라 1초 이상 노출이 쉽게 채워집니다 (Active View 조건 충족)
- 모바일 기준 화면 상단에서 약 400~600px 지점 — 첫 화면 또는 첫 스크롤에 들어옵니다
  (실측: 390px 뷰포트에서 y=422px, 첫 화면 안)

### 왜 AD 4를 FAQ **앞**에 두는가

관련 글 링크가 광고 두 개 사이에 끼면 클릭률이 떨어집니다. **그 링크 클릭이
전면광고(Vignette) 수익의 출발점**이므로 링크 위아래에 여백을 줘야 합니다.
AD 4를 FAQ 앞으로 올리면 완독 구간 노출은 그대로 가져가면서 링크가 살아납니다.

실측 밀도 (본문 2,172자 기준): AD1 이후 615자 / AD2 421자 / AD3 459자 / AD4 399자
— 300~500단어 권장 간격에 부합합니다.

## 3. 광고 개수 — 늘릴수록 좋은 게 아니다

| 본문 길이 | 권장 본문 광고 수 |
|---|---|
| 800~1,200자 (이슈성) | 2~3개 |
| 1,500~2,500자 (정보성) | 4~5개 |
| 3,000자 이상 | 5~6개 |

여기에 앵커 1 + 전면광고가 별도로 붙습니다. 이 이상은 이탈률이 올라가 **총수익이 떨어집니다.**

## 4. CLS(레이아웃 이동) 방지 — 오클릭 예방

광고가 늦게 로드되며 본문이 밀리면 오클릭이 발생합니다. 오클릭은 무효 트래픽으로 잡힐 수 있고, 코어 웹 바이탈 점수도 떨어집니다.

슬롯마다 **예상 높이를 미리 예약**합니다.

```css
.ad-inline{ min-height:280px; }              /* 336×280 */
@media(max-width:600px){
  .ad-inline{ min-height:250px; }            /* 300×250 */
}
.ad-multiplex{ min-height:400px; }
```

## 5. 측정과 개선 루프

발행 후 그냥 두면 안 됩니다. 애드센스 리포트에서 주 1회 확인합니다.

| 지표 | 정상 범위 | 벗어나면 |
|---|---|---|
| **조회 가능 Active View** | **50% 이상** | 50% 미만이면 광고를 아래로 내리거나 지연로딩 해제 |
| 페이지 RPM | 니치별 상이 | 낮으면 키워드 단가부터 점검 |
| **CTR** | 1~5% | **10% 초과 시 즉시 점검** — 오클릭/무효 트래픽 경고 신호 |
| 세션당 PV | 1.3 이상 | 낮으면 내부링크 보강 |

**CTR이 비정상적으로 높은 건 좋은 신호가 아닙니다.** 오클릭이 잡히고 있다는 뜻이라 계정 위험 신호로 읽어야 합니다.

### 개선 우선순위

1. 가시성 50% 미만인 슬롯 위치 조정
2. 세션당 PV 올리기 (내부링크) → 전면광고 노출도 함께 증가
3. 336×280이 나오도록 본문 폭 확보
4. 페이지 속도 (광고 로드 전 이탈 방지)
5. 그 다음에야 광고 개수 조정

## 6. 기대 효과

조사 자료 기준, **사이즈와 배치를 제대로 조합하면 기본 설정 대비 30% 이상 수익 증가**가 가능합니다. 다만 이는 배치만의 효과이고, 키워드 단가가 5~10배 차이 나는 것에 비하면 작습니다.

**순서를 지키세요: 고단가 키워드 → 트래픽 → 배치 최적화.** 배치로 5배를 만들 수는 없습니다.
