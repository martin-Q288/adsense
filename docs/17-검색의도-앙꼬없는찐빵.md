# 17. 검색 의도 — 앙꼬 없는 찐빵을 만들지 않으려면

2026-08-03. 말복 원고에 대한 지적에서 나온 문서.

> "한국인의 정서와 문화, 왜 저 키워드를 검색할지에 대한 깊은 고민이
> 담겨 있지 않은, 단순히 키워드만 가지고 쓴 앙꼬 없는 찐빵 같은 글이다.
> 아무리 있는 척 써도 사람들은 딱 보면 안다."

맞는 지적이라 규칙으로 남긴다.

## 1. 무엇이 잘못됐나

첫 문장이 이랬다.

> 2026년 말복은 8월 14일 금요일입니다.

**폰 달력이 이미 알려주는 정보다.** 검색할 이유가 없는 것을 글의 결론으로
놓았다. 그다음은 삼계탕 칼로리와 제철 재료였다. 백과사전이지 답이 아니다.

키워드 도구가 "말복 = 검색량 큼"이라고 알려줬고, 나는 말복에 **대한** 글을
썼다. 검색한 사람이 **무엇을 결정하려고** 왔는지는 묻지 않았다.

## 2. 진짜 의도 — 말복의 경우

한국에서 복날은 날짜가 아니라 **"챙김"의 의무**다. 안 챙기면 서운해지는
관계가 걸려 있어서 검색한다. 실제 검색자는 이렇게 나뉜다.

| 누가 | 진짜 묻는 것 | 내 글에 있었나 |
|---|---|---|
| 팀 막내·총무 | 복날 회식 언제 잡지 | 없음 |
| 따로 사는 자식 | 부모님께 뭘 보내드리지 | 없음 |
| 결혼한 사람 | 양가 다 챙겨야 하나 | 없음 |
| 1인 가구 | 혼자인데 이날 뭐 먹지 | 없음 |
| 그냥 궁금 | 날짜 | 이것만 있었음 |

가장 작은 집단에게만 답한 글이었다.

## 3. 아무도 안 짚은 것을 찾아라 — 이게 앙꼬다

2026년 말복에는 달력만 봐서는 안 보이는 사실이 하나 있었다.

> **8월 14일(금)이 4일 연휴의 첫날이다.**
> 다음 날 광복절(토), 8월 17일 대체공휴일(월).
> 즉 이날 회식을 잡으면 팀 절반이 연차다.

이건 누가 짚어줘야 아는 정보다. **블로그가 존재할 이유가 여기에 있다.**
달력이 알려주는 것을 다시 쓰면 존재 이유가 없다.

앙꼬를 찾는 질문은 하나다.

> 이 글에서 **달력·공식 사이트·AI 요약이 못 주는 것**이 무엇인가?
> 하나도 없으면 그 글은 쓰지 않는다.

## 4. 발행 전 의도 점검 (필수)

키워드를 고른 뒤, 원고를 쓰기 **전에** 아래를 채운다. 못 채우면 주제를
바꾼다.

- [ ] **누가 검색하나** — 직업·상황까지. "사람들"은 답이 아니다
- [ ] **무엇을 결정하려고 왔나** — 정보 수집이 아니라 결정이다.
      날짜/금액/장소/할지 말지 중 무엇을 정하려는가
- [ ] **검색하기 직전에 무슨 일이 있었나** — 회식 총대를 멨다, 고지서를
      받았다, 잔금일이 잡혔다, 퇴사 통보를 받았다
- [ ] **안 하면 뭐가 곤란해지나** — 돈을 잃나, 관계가 상하나, 눈치가
      보이나. 이 감정이 글의 도입부가 된다
- [ ] **달력·공식 사이트가 못 주는 것이 뭔가** — 없으면 접는다

## 5. 도입부는 "왜 왔는지 알아맞히기"로 연다

결론부터 쓰라는 규칙(docs/14)은 유효하다. 다만 **결론 다음 문장이
독자의 상황을 짚어야** 한다.

```
나쁨
  2026년 말복은 8월 14일 금요일입니다.
  초복은 7월 15일, 중복은 7월 25일이었습니다.

좋음
  2026년 말복은 8월 14일 금요일입니다. 날짜만 필요하셨다면 여기서 끝입니다.

  그런데 이맘때 말복을 검색하는 분들은 대개 이유가 따로 있습니다.
  회식 날짜를 잡아야 하거나, 부모님께 뭘 보내드릴지 정해야 하거나,
  혼자 사는데 이날 뭘 먹나 싶어서입니다.
```

독자가 **"어, 내 얘기네"** 하는 지점이 있어야 끝까지 읽는다.

## 6. 한국적 맥락을 빼면 남는 게 없는 주제들

키워드만 보면 정보성인데 실제로는 관계·눈치·체면이 걸린 주제가 있다.
이런 주제에서 정보만 쓰면 반드시 앙꼬 없는 찐빵이 된다.

| 주제 | 표면 | 실제 |
|---|---|---|
| 복날·명절 음식 | 뭘 먹나 | 누구를 챙기나, 안 하면 서운해하나 |
| 축의금·부의금 | 얼마 내나 | 관계 대비 적정선, 적게 내면 티 나나 |
| 명절 귀성 | 언제 출발 | 양가 배분, 안 가면 되나 |
| 어린이집·학원비 | 얼마 | 남들은 얼마나 시키나 |
| 경조사 휴가 | 며칠 | 눈치 안 보고 쓰는 법 |
| 퇴사·이직 | 절차 | 언제 말하나, 배신자 소리 안 듣는 법 |

**부담을 덜어주는 한 문장**을 반드시 넣는다. 위 말복 원고의
"부담되면 안 하셔도 됩니다. 대신 전화는 하세요"가 그것이다.
이런 문장이 체류시간과 재방문을 만든다.

## 7. 기존 9편 판정

같은 잣대로 다시 봤다.

| 원고 | 의도 명확성 | 상태 |
|---|---|---|
| 쿠팡 고객센터 | 상 — 지금 전화 걸고 싶다 | 그대로 좋음 |
| 전입신고·확정일자 | 상 — 잔금일이 잡혔다 | 그대로 좋음 |
| 광복절 대체공휴일 | 상 — 쉬나 안 쉬나, 연차 언제 | 그대로 좋음 |
| 에어컨 전기요금 | 상 — 고지서가 무섭다 | 그대로 좋음 |
| 실업급여 조건 | 중 — 내가 받나 못 받나 | 조건 나열이 앞에 옴. 도입부 손볼 것 |
| 근로장려금 | 중 — 왜 안 들어오지 | 재산 탈락 얘기를 더 앞으로 |
| 퇴직금 계산 | 중 — 덜 준 거 아닌가 | 계산식이 먼저. 의심을 먼저 다뤄야 |
| 전세보증보험 | 중 — 가입해야 하나 불안 | 기관 비교가 먼저. 불안을 먼저 |
| 말복 | 하 → 재작성 완료 | 회식·부모님·1인가구 축으로 다시 씀 |

**중 등급 4편은 내용은 맞는데 순서가 틀렸다.** 독자가 품고 온 감정
(의심·불안·억울함)을 먼저 받아주고 정보를 주는 순서로 도입부만
바꾸면 된다. 전면 재작성은 필요 없다.
