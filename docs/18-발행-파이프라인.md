# 18. 발행 파이프라인 — 주차에 묶이지 않는 실행 구조

2026-08-04. 구글드라이브 자료(알파남 챌린지클래스) 전량 확인 후 정리.

## 1. 자료에서 확정된 것

| 자료 | 결론 |
|---|---|
| 부록_2026 연간 수익형 키워드 | **8월은 전세·부동산이 연간 최고단가 구간.** "전세사기·DSR·주담대 비교 시리즈 강력 추천" |
| 황금 키워드 6단계 | 월간검색량 **1,000~30,000** + **40대 이상**이 검색 + 비교·후킹 조합 |
| 부록_고단가 황금키워드 30개 | 키워드에 **행동**(신청·조회·비교·확인·계산)이 붙어야 광고 단가가 붙는다 |
| 6_구글 상위노출 공략집 | 검색 의도 4분류 중 **상업 조사형**이 수익에 유리. 체류시간·내부링크가 순위를 만든다 |
| 4주 시스템 | **정보형 + 경험/후기 + 비교/추천** 3종이 같이 돌아야 자동으로 돈이 된다 |

자료의 "고단가만 쫓지 마라"도 그대로 반영한다. 고단가에 갇히면 글이 안 써진다.
**40대 이상의 검색 의도에 맞추면 단가는 따라온다.**

## 2. 4주 시스템을 주차에서 푼 이유

원 자료는 1주차 세팅 → 2주차 네이버 → 3주차 외부유입 → 4주차 완성이다.
우리는 이미 티스토리가 있고 도메인 나이도 있다. **주차는 신규 개설자 기준이라
우리에게 그대로 맞지 않는다.** 그래서 주차를 단계가 아니라 **채널 축**으로 바꿨다.

| 원 자료 | 우리 축 | 지금 상태 |
|---|---|---|
| 1주차 기초 세팅 | T1 티스토리 | 있음. 자동광고 설정 완료 |
| 2주차 네이버 홈판 | N 네이버 | 원고 1편 대기 |
| 3주차 외부 유입 | 인스타·쓰레드·쇼츠 | 미착수 |
| 4주차 자동화 | 파이프라인 | **이 문서** |

언제 시작하든 오늘 날짜만 넣으면 그 시점에서 할 일이 나온다.

## 3. 명령 네 개

```bash
python3 tools/pipeline.py today                    # 오늘 뭘 쓸지 (등급·시즌 순)
python3 tools/pipeline.py new "전세대출 조건 2026"   # 원고 틀 생성
python3 tools/pipeline.py status                   # 발행 준비 상태 점검
python3 tools/pipeline.py build                    # 텍스트·썸네일·아티팩트 일괄 생성
```

`today` 는 `tools/keywords_2026.py` 의 12개월 캘린더를 읽는다. 자료의 키워드와
CPC 등급을 그대로 옮겨 놓은 것이라, 달이 바뀌면 후보도 자동으로 바뀐다.

`new` 로 만든 원고 틀에는 docs/17 검색 의도 네 칸이 프런트매터에 박혀 있다.
**앙꼬 칸을 못 채우면 그 글은 쓰지 않는다.**

`status` 는 원고별로 의도·앙꼬·내부링크가 채워졌는지 표로 보여준다.
× 가 있으면 발행 전에 채운다.

`build` 는 원고 → 순수 텍스트 → 썸네일 → 아티팩트까지 한 번에 돈다.
썸네일은 이미 있으면 건너뛴다.

## 4. 자동화한 것과 못 한 것

**자동화됨**
- 월별 키워드 후보 산출 (등급·시즌 정렬)
- 원고 틀 생성 (검색 의도 체크리스트 포함)
- 마크다운 → 에디터용 순수 텍스트 (표 풀기, 모바일 줄바꿈)
- 썸네일 PNG 렌더링
- 아티팩트 빌드 (우선순위·마감 표시)

**수동으로 남는 것 — 그리고 남겨야 하는 것**
- **원고 본문.** 자료도 "AI가 만든 글을 그대로 올리지 말라"고 못박는다.
  구글 콘텐츠 품질 업데이트가 걸러낸다
- **연관검색어 확인.** 발행 전 구글·네이버에서 직접 쳐봐야 한다
- **앱 붙여넣기·발행.** 티스토리·네이버 모두 공개 API로 자동 발행할 수 없다
- **내부링크 연결.** 발행 후 실제 URL이 생겨야 걸 수 있다

발행 자체를 자동화하려면 브라우저 자동화가 필요한데, 두 플랫폼 모두 약관상
문제가 되고 계정 제재 위험이 있다(docs/04). 하지 않는다.

## 5. 하루 운영 루틴

```
아침   pipeline.py today  →  후보에서 1~2개 고른다
       구글·네이버에 키워드를 직접 쳐서 연관검색어 확인
       pipeline.py new "키워드"  →  틀 생성
       프런트매터 검색 의도 4칸을 먼저 채운다 (앙꼬 없으면 주제 교체)

낮     본문 작성. 정보형·후기형·비교형 중 무엇인지 정하고 쓴다

저녁   pipeline.py status  →  × 없는지 확인
       pipeline.py build   →  산출물 생성
       Artifact 배포  →  폰으로 열어 제목·본문 복사해 발행
       발행 후 서치콘솔 URL 검사 → 색인 요청
```

## 6. 8월 남은 기간 배치

자료가 8월을 부동산 최고단가 구간으로 지목했다. T1의 축을 여기에 맞춘다.

| 순서 | 키워드 | 등급 | 상태 |
|---|---|---|---|
| 1 | 전세사기 피하는 법 | ★★★ | **작성 완료** |
| 2 | 전세대출 조건 2026 | ★★★ | 대기 |
| 3 | 월세 세액공제 | ★★★ | 대기 |
| 4 | 주택담보대출 금리 비교 | ★★★ | 대기 |
| 5 | DSR 계산 방법 | ★★★ | 대기 |
| 6 | 부동산 중개수수료 계산 | ★★ | 대기 |

이 여섯을 **서로 내부링크로 묶으면** 한 번 들어온 독자가 여러 편을 본다.
자료가 강조한 체류시간·페이지뷰가 여기서 나온다. 기존 전입신고·전세보증보험
원고 2편도 같은 묶음에 넣는다. **전세 8부작**이 8월의 축이다.

시의성 원고(말복·광복절)는 마감이 있으니 이 축과 별개로 먼저 나간다.
