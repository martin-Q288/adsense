# 08. 광고 배치 — 수익 극대화와 정책 준수의 경계선

## 결론 요약

| 하고 싶은 것 | 위반 방식 (계정 사망) | 합법 방식 (동일 효과) |
|---|---|---|
| 전면광고 띄우기 | 가짜 버튼 클릭 시 광고 강제 노출 | **자동광고 → 전면광고(Vignette) ON** — 링크 클릭 시 자동 표시 |
| 클릭 유도 | 빨간 반짝이는 버튼, "여기를 눌러주세요" | 광고를 콘텐츠 흐름 안에 배치 + 체류시간 상승 |
| 페이지뷰 늘리기 | 강제 페이지 분할, 리다이렉트 | 진짜 유용한 내부링크 3~5개 |
| 모바일 RPM | 광고 위 화살표, 콘텐츠 위장 | **앵커광고(Anchor) ON** |

## 1. 절대 하면 안 되는 것 (계정 영구정지 + 미지급 수익 몰수)

애드센스 프로그램 정책에 명시된 항목입니다.

- **인위적 클릭·노출 생성** — 광고 클릭은 실제 사용자 관심에서 나와야 합니다
- **클릭 유도 문구** — "광고를 클릭해주세요", "여기를 눌러주세요", "지원해주세요"
- **광고를 가리키는 화살표·강조 표시**
- **광고 위/주변에 "추천", "다운로드", "다음" 같은 라벨** — 광고를 콘텐츠나 버튼으로 오인하게 만드는 모든 배치
- **광고와 클릭 가능한 요소 사이 20px 미만 이격** — 오클릭 유발로 간주됩니다
- **콘텐츠를 가리는 강제 팝업** — 닫기(X) 버튼이 작거나 숨겨져 있으면 침입형 인터스티셜로 분류
- **버튼 클릭을 광고 노출 트리거로 삼는 스크립트**

마지막 항목이 특히 중요합니다. **"버튼을 누르면 광고가 뜬다"는 구조 자체가 인위적 노출 생성입니다.** 버튼 디자인이 얼마나 자연스럽든 상관없습니다.

### 왜 이게 손해인가 (윤리가 아니라 손익 계산)

- 정지는 대부분 **영구**이고 이의신청 성공률이 낮습니다
- **미지급 수익이 전액 몰수**됩니다. 8월 내내 번 돈이 그대로 사라집니다
- 정지된 사람과 연결된 신규 계정도 대부분 재정지됩니다
- 참고 채널 운영자 본인도 *"6개월간 2억을 투자, 전계정 정지"* 영상을 올렸습니다

승인된 계정 1개가 이 프로젝트의 유일한 자산입니다.

## 2. 전면광고를 합법적으로 켜는 법

**Vignette(전면광고)는 구글 공식 형식입니다.** 기본 동작이 "사용자가 사이트 내 링크를 클릭할 때 전체화면으로 표시, 언제든 건너뛰기 가능"입니다.

설정 경로:
```
애드센스 → 광고 → 사이트별 → (내 블로그) 편집
  → 자동 광고 ON
  → 전면 광고(Vignette) ON
  → 앵커 광고(Anchor) ON
  → 광고 로드 수: 중간~높음
```

**즉 원하시던 동작을 구글이 이미 제공합니다.** 가짜 버튼이 필요 없고, 오히려 가짜 버튼은 이 기능을 쓰면서도 정책 위반으로 잡히게 만듭니다.

전면광고 노출을 늘리는 합법적 방법은 하나뿐입니다 — **독자가 실제로 누르고 싶은 내부링크를 많이 까는 것.** 관련 글 링크가 많을수록 링크 클릭이 늘고, 그때마다 Vignette가 뜹니다. 결과는 같은데 계정은 안전합니다.

주의: 전면광고를 켜면 **이탈률이 올라갑니다.** 켜고 2주간 페이지 RPM과 세션당 PV를 비교해서 순증인지 확인하세요. 무조건 이득이 아닙니다.

## 3. 실제로 RPM을 올리는 것 (검증된 순서)

효과 큰 순서입니다.

### 3-1. 광고 배치 위치

| 위치 | 형식 | 비고 |
|---|---|---|
| 첫 문단 직후 | 디스플레이(반응형) | 뷰포트 안에 들어오는 첫 광고. 가장 중요 |
| 목차 직후 | 인아티클 | 스크롤 시작 지점 |
| H2 2~3개마다 | 인아티클 | 본문 흐름 안에 자연 삽입 |
| 글 하단 | 멀티플렉스 | PV/세션 상승 효과 |
| 모바일 하단 고정 | 앵커 | 자동광고로 켜기 |

**광고 개수를 늘리는 건 어느 지점부터 역효과입니다.** 이탈률이 올라가 총수익이 떨어집니다. 본문 1,500자 기준 3~4개가 적정선입니다.

### 3-2. RPM을 결정하는 진짜 변수

광고 배치보다 이쪽이 더 큽니다.

1. **키워드 단가** — 금융/보험/법률은 생활정보의 5~10배. 배치 최적화로 5배를 만들 수는 없습니다
2. **체류시간과 세션당 PV** — 표, FAQ, 내부링크가 직접적으로 올립니다
3. **페이지 로딩 속도** — 광고가 로드되기 전 이탈하면 노출 자체가 없습니다
4. **모바일 최적화** — 한국 트래픽의 80~90%가 모바일

### 3-3. CLS(레이아웃 이동) 방지

광고 자리를 미리 잡아두지 않으면 콘텐츠가 밀리면서 오클릭이 발생합니다. 오클릭은 무효 트래픽으로 잡힐 수 있고, 코어 웹 바이탈 점수도 떨어집니다.

```css
.ad-slot{ min-height:280px; }        /* 데스크톱 */
@media(max-width:600px){
  .ad-slot{ min-height:250px; }      /* 모바일 */
}
```

## 4. 티스토리 적용 체크리스트

- [ ] 자동광고에서 **전면광고·앵커광고 ON**
- [ ] 본문 광고는 수동 배치 (자동 전면 위임은 레이아웃이 깨집니다)
- [ ] 광고와 링크·버튼 사이 **20px 이상** 이격
- [ ] 광고 슬롯에 `min-height` 지정 (CLS 방지)
- [ ] 모바일 화면에서 먼저 검수
- [ ] ads.txt 설정
- [ ] 개인정보처리방침 페이지
- [ ] 쿠팡 링크 글에 수수료 고지 문구
- [ ] 애드센스 리포트 주 1회 확인 — **CTR 10% 초과 시 즉시 점검**

CTR이 비정상적으로 높으면 좋은 신호가 아니라 **오클릭 또는 무효 트래픽 경고 신호**입니다.

## 5. 공격받았을 때

경쟁자가 고의로 광고를 반복 클릭하는 공격이 실제로 있습니다.

- 애드센스가 대부분 자동 필터링합니다
- 이상 패턴 발견 시 **무효 클릭 신고 양식**으로 선제 신고하세요. 신고 이력이 있으면 정지 판단에서 유리합니다
- 해당 IP를 광고 게재 차단 목록에 추가
