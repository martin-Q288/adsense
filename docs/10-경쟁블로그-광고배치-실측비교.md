# 10. 상위노출 블로그 광고 배치 실측 — 벤치마킹과 자기 점검

조사 자료(docs/09)만으로 배치를 정했던 것을 실제 상위노출 블로그 **10곳의 원본 HTML을 파싱해서 검증**했습니다. 분석 스크립트: `tools/analyze_ads.py`

## 2. 가장 중요한 발견 세 가지

### 2-1. 10곳 전부 자동광고가 켜져 있다. 예외 없음.

수동 유닛만으로 운영하는 곳이 **한 곳도 없습니다.** 그리고 4곳은 아예 **수동 0개, 자동광고만**으로 돌립니다 — 알파남 본인 사이트(adsensefarm.kr) 포함입니다.

이게 제 설계의 가장 큰 구멍이었습니다. 저는 수동 5개를 깔아놓고 "자동광고도 켜세요"라고 안내했는데, **그대로 하면 실제 페이지에 광고가 8~10개 뜹니다.** 자동광고가 본문에 알아서 더 꽂기 때문입니다. 이탈률 폭증 + 정책 리스크입니다.

### 2-2. 실제 밀도는 1,000~1,300자당 1개. 제 배치는 434자당 1개였습니다.

| | 광고당 본문 자수 |
|---|---|
| financialwook | 1,064 |
| wegotogether | 1,079 |
| joyjane | 1,308 |
| **제 초안** | **434** ← 2.5~3배 과밀 |

**원인은 제 환산 오류입니다.** 조사 자료의 "300~500 words마다 1개"를 한국어 글자 수로 잘못 옮겼습니다. 영어 300~500단어는 한국어로 **약 900~1,500자**입니다. 제가 이걸 434자로 계산해 광고를 2배 이상 촘촘하게 깔았습니다.

info-exclusive.com이 258자당 1개로 더 조밀한데, 본문이 1,547자뿐이라 광고가 콘텐츠보다 많은 구조입니다. 벤치마킹 대상이 아니라 피해야 할 사례입니다.

### 2-3. 첫 광고 깊이는 6~35%, 중앙값 15~18%

제 배치는 결론 박스 뒤 = 본문의 **약 8% 지점**입니다. 범위 안에 있고, 상위권(빠른 편)입니다. **이 부분은 유지해도 됩니다.**

## 3. 벤치마킹할 것 (반영)

| 발견 | 조치 |
|---|---|
| 전원 자동광고 ON | 자동광고를 전제로 재설계. **앵커·전면만 ON, 페이지 내 광고는 OFF**로 겹침 차단 |
| 밀도 1,000자/광고 | 수동 유닛 **5개 → 3개**로 축소 |
| `data-ad-format="auto"` + `data-full-width-responsive="true"` 표준 | ins 태그 템플릿에 명시 |
| `fluid`(인아티클) + `autorelaxed`(멀티플렉스) 병용 | 슬롯별 포맷 지정 |
| sticky 사이드바 (알파남·policy.ambitstock) | 주석이 아니라 정식 스니펫으로 승격 |

## 4. 제 배치가 더 나은 부분 (유지)

실측 10곳에서 **아무도 안 하고 있는** 것들입니다.

| 항목 | 실측 현황 | 제 배치 |
|---|---|---|
| **CLS 방지 (min-height 예약)** | **0/10** | 슬롯별 브레이크포인트 예약 |
| **FAQ 구조화 데이터** | 2/10 (foxcg, moneylog2030) | 적용 |
| **결론 선제시 구조** | 드묾 | 상단 결론 박스 |
| 광고-링크 이격 명시 | 관리 흔적 없음 | 28px 고정 |
| 지연 로딩 정책 | 10/10 미적용 | 상단 2개 제외 원칙 |

CLS 방지는 특히 의미가 큽니다. 광고가 늦게 로드되며 본문이 밀리면 **오클릭**이 나고, 오클릭은 무효 트래픽으로 잡힐 수 있습니다. 상위 블로그들도 이건 관리하지 않고 있어서, 여기서 차별화가 가능합니다.

## 5. 수정된 배치 기준

본문 2,000~2,500자 기준입니다.

```
본문 광고 3개 (약 700자 간격)
  AD 1  결론 박스 뒤 / 목차 앞        ← 본문 8~15% 지점
  AD 2  본문 중반 (약 40~50%)
  AD 3  관련 글 앞 (약 85~90%)  멀티플렉스

자동광고 설정
  · 앵커 광고        ON   ← 모바일 하단 고정
  · 전면 광고        ON   ← 링크 클릭 시 Vignette
  · 페이지 내 광고   OFF  ← 수동 3개와 겹치지 않게

데스크톱
  · sticky 사이드바 (스킨에 1회 삽입)
```

수동 3개 + 앵커 1 + 전면광고 = 실질 노출 4~5개. 실측 상위 블로그와 같은 밀도입니다.

### 자동광고를 전면 위임하는 대안

알파남·policy.ambitstock·moneylog2030 방식입니다. 수동 유닛 0개로 두고 자동광고에 전부 맡깁니다.

- 장점: 구글이 알아서 최적화, 관리 비용 0
- 단점: 레이아웃 통제 불가, CLS 방지 불가, 배치 실험 불가

**초기 2주는 수동 3개 방식으로 데이터를 쌓고, 그 뒤에 자동 전면 위임과 A/B 비교**하는 걸 권합니다. 어느 쪽이 나은지는 니치와 스킨에 따라 달라집니다.

## 6. 수정 결과 — 실측 밴드와 최종 대조

| | 광고 수 | 본문(자) | 광고당 자수 | 깊이 % |
|---|---|---|---|---|
| financialwook | 3 | 3,192 | 1,064 | 15 / 46 / 85 |
| wegotogether | 2 | 2,158 | 1,079 | 18 / 92 |
| joyjane | 2 | 2,615 | 1,308 | 35 / 58 |
| **제 초안 (수정 전)** | 5 | 2,172 | **434** | 8/25/45/70/88 |
| **제 수정본** | **3** | 2,168 | **722** | **8 / 55 / 94** |

깊이 분포는 financialwook(15/46/85)과 같은 모양이 됐습니다. 밀도 722자는 실측 밴드(1,064~1,308)보다 **여전히 조밀한 편**입니다. 다만 이는 글이 짧아서 생기는 차이입니다 — financialwook은 3,192자에 3개, 제 글은 2,168자에 3개입니다.

**정직하게 말하면 722자는 관찰된 범위의 공격적인 쪽 끝입니다.** 2개로 줄이면 1,084자가 되어 wegotogether와 정확히 일치합니다. 발행 후 이탈률과 페이지 RPM을 보고 판단하세요.

### 글 길이별 권장 광고 수

| 본문 길이 | 수동 광고 수 | 광고당 자수 |
|---|---|---|
| ~1,200자 (이슈성) | **2개** | ~600 |
| 1,500~2,500자 (정보성) | **3개** | ~700~830 |
| 3,000자 이상 | **4개** | ~750 |

여기에 앵커 1 + 전면광고가 별도로 붙습니다.

## 7. 재현 방법

```bash
python3 tools/analyze_ads.py "https://예시.com/글주소"
```

원본 HTML을 받아 광고 유닛 위치를 본문 글자 수 기준으로 계량합니다. 경쟁 블로그를 주기적으로 재측정해서 이 문서를 갱신하세요.
