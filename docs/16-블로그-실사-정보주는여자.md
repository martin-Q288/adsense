## 2. 실사 당시 관찰 — 기존 글의 주제

기존 72편의 성격은 이렇습니다.

- 생활: 수세미 살균, 여름 습기 제거, 식초 청소 주의 조합
- 건강: 음식 궁합(아보카도·계란·두부), 혈당 낮추는 간식, 제철 식재료
- 분량: 편당 1,500~2,500자 수준, 얇은 글이 아님

**즉 이 블로그의 자산은 "생활·건강 실용정보"입니다.**

그런데 제가 8월 2일에 쓴 글은 실업급여, 퇴직금, 전세보증보험,
근로장려금이었습니다. **금융·정책입니다. 하나도 안 맞습니다.**

구글은 사이트 단위의 주제 일관성을 봅니다. 생활·건강으로 72편을
쌓아둔 도메인에 갑자기 금융·정책을 올리면 기존 신호를 활용하지
못할 뿐 아니라, 주제가 흩어져 오히려 손해입니다.

> 사용자가 지적한 "쿠팡 고객센터, 넷플릭스 환불 같은 것도 고려하라"는

## 3. 15개월 휴면이 뜻하는 것

**유리한 점**
- 도메인 나이 1년 이상
- 72편이 이미 색인 이력을 가짐
- 애드센스 승인 완료 상태

**불리한 점**
- 크롤링 주기가 길어졌을 가능성이 큼. 재개 직후 색인이 느립니다
- 대표 글 제목으로 검색했을 때 자사 글이 상위에 잡히지 않았습니다.
  색인에서 밀렸거나 순위가 크게 내려간 상태로 보입니다
  (검색 환경 차이일 수 있어 단정하지 않습니다. 서치콘솔 확인 필요)

**재개 초기에 할 일**
1. 구글 서치콘솔에서 색인 상태와 커버리지 확인
2. 사이트맵 재제출
3. 신규 글은 발행 즉시 URL 검사 → 색인 요청
4. 초반 2주는 발행 간격을 촘촘히 해 크롤링 주기를 되살립니다
